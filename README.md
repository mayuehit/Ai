# 谁是卧底 - 微信小程序游戏

一个基于微信小程序的"谁是卧底"社交推理游戏。

## 🎮 游戏介绍
"谁是卧底"是一款经典的社交推理游戏，玩家分为平民和卧底两个阵营，通过描述词语来推理出卧底身份。

## 👥 项目角色
- **产品经理**: 负责需求分析和产品规划
- **架构师**: 负责系统架构设计
- **开发工程师**: 负责功能实现
- **测试工程师**: 负责质量保证
- **协调者**: 负责项目协调和进度管理

## 🚀 功能特性
- [ ] 用户登录与身份验证
- [ ] 游戏房间创建与加入
- [ ] 角色分配（平民/卧底）
- [ ] 词语库管理
- [ ] 游戏回合流程
- [ ] 投票与推理系统
- [ ] 实时聊天功能
- [ ] 游戏结果统计

## 🛠️ 技术栈
- **前端**: 微信小程序 + WXML + WXSS + JavaScript
- **后端**: Node.js + Express / 云开发
- **数据库**: MongoDB / 云数据库
- **实时通信**: WebSocket

## 📁 项目结构
