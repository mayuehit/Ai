# 产品需求文档 - 谁是卧底微信小程序

## 1. 项目概述
### 1.1 产品背景
"谁是卧底"是一款经典的社交推理游戏，适合朋友聚会、团队建设等场景。通过微信小程序形式，让用户可以随时随地与朋友进行游戏。

### 1.2 目标用户
- 年轻人群体（18-35岁）
- 朋友聚会场景
- 团队建设活动
- 线上社交需求

## 2. 核心功能

### 2.1 用户系统
- 微信一键登录
- 用户昵称和头像设置
- 游戏历史记录

### 2.2 游戏房间
- 创建游戏房间
- 加入房间（房间号/二维码）
- 房间人数限制（4-10人）
- 房间设置（游戏轮数、时间限制）

### 2.3 游戏流程
1. **准备阶段**: 玩家加入房间，房主开始游戏
2. **角色分配**: 系统随机分配平民和卧底角色
3. **词语分配**: 平民获得相同词语，卧底获得相似词语
4. **描述阶段**: 玩家轮流描述自己的词语
5. **投票阶段**: 玩家投票选出怀疑的卧底
6. **揭晓阶段**: 公布投票结果和真实身份
7. **计分阶段**: 根据游戏结果计分

### 2.4 词语库系统
- 内置常用词语库
- 支持自定义词语
- 词语分类（简单/普通/困难）

### 2.5 社交功能
- 游戏内实时聊天
- 好友系统
- 战绩分享

## 3. 非功能需求

### 3.1 性能要求
- 页面加载时间 < 2秒
- 实时消息延迟 < 500ms
- 支持同时在线1000个房间

### 3.2 兼容性
- 支持微信iOS/Android客户端
- 适配不同屏幕尺寸
- 支持微信最新版本

### 3.3 安全性
- 用户数据加密存储
- 防止作弊机制
- 内容审核过滤

## 4. 版本规划

### V1.0 (MVP)
- 基础游戏流程
- 微信登录
- 基础词语库
- 实时游戏通信

### V1.1
- 好友系统
- 战绩统计
- 自定义词语
- 游戏回放

### V1.2
- 语音描述功能
- 主题皮肤
- 成就系统
- 排行榜

## 5. 成功指标
- 日活跃用户(DAU) > 1000
- 用户留存率(7日) > 30%
- 平均游戏时长 > 15分钟
- 用户评分 > 4.5/5

## 6. 风险与挑战
- 实时通信稳定性
- 防作弊机制设计
- 词语内容审核
- 用户增长与服务器成本
